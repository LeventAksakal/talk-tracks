# Which licence-free lectures seed the demo rooms?

## Question
Which lectures do we loop in the public demo rooms (decision 0006), and how many rooms?

## Context
Each lecture is sent once through the Meta API (speech recognition, translation, slide description, chapters), so it
must be public or licence-checked (your rule: nothing private to Meta). It needs visible slides for the description
track, clear single-speaker audio, and a licence that allows reuse with modification (we add tracks) and
redistribution (we re-stream the video). Shorter is cheaper: 10–20 minutes per lecture is plenty for a loop.

## Options
- **A. Two or three CC BY lectures with slides** (for example university open courseware or conference talks released
  under CC BY). Real content, low cost; we must check each licence and credit it in the README.
- **B. One lecture, one room.** Cheapest and simplest; less variety for judges.
- **C. A short talk you record with your own slides.** Clean rights and a topic we choose (could be about Talk Tracks
  itself); takes your time.

## Recommendation
A, with two lectures in different subjects; I shortlist candidates with their licences for you to pick from.

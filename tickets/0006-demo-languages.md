# Which translation languages does the demo show?

## Question
Which languages get a translation track in the demo rooms?

## Context
Each language is one more agent and, for looped rooms, a one-time translation cost per lecture. Languages named in
code today: English, Turkish, Spanish, German, Arabic, French.

## Options
- **A. Turkish and Spanish.** Turkish you can judge yourself; Spanish reaches many judges.
- **B. Turkish, Spanish and Arabic.** Arabic shows the viewer handles right-to-left text.
- **C. One language.** Cheapest; "one track per language" is less visible.

## Recommendation
B: the right-to-left case is a cheap, visible accessibility point.
